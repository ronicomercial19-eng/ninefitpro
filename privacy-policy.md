# Política de Privacidade - 9FIT

**Última atualização: Janeiro 2025**

## 1. Informações Gerais

A **9FIT** é um aplicativo de fitness que oferece treinos personalizados e acompanhamento de evolução física. Esta política descreve como coletamos, usamos e protegemos seus dados pessoais.

## 2. Dados Coletados

### 2.1 Dados Obrigatórios
- Nome completo
- E-mail
- Data de nascimento
- Dados antropométricos (peso, altura)
- Histórico de exercícios

### 2.2 Dados Opcionais
- Foto de perfil
- Dados de saúde e condicionamento físico
- Preferências de treino

## 3. Uso dos Dados

Utilizamos seus dados para:
- Personalizar treinos e exercícios
- Acompanhar sua evolução física
- Melhorar nossos serviços
- Enviar notificações importantes

## 4. Compartilhamento

Seus dados pessoais **NÃO** são compartilhados com terceiros, exceto:
- Quando exigido por lei
- Para processamento de pagamentos (dados criptografados)

## 5. Segurança

- Todos os dados são criptografados
- Acesso restrito apenas a pessoal autorizado
- Backups seguros e regulares

## 6. Seus Direitos

Você pode:
- Acessar seus dados pessoais
- Corrigir informações incorretas
- Excluir sua conta e dados
- Exportar seus dados
