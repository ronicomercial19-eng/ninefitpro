# Snapshots históricos do planejamento

Estes SQLs registram a view e as políticas observadas em outubro de 2026. Foram preservados para consulta, mas não são migrações executáveis: a `main` recebeu alterações posteriores na mesma view e nas mesmas políticas. Executar estes snapshots após as migrações mais recentes poderia substituir o contrato publicado. Qualquer ajuste futuro deve partir da definição atual do banco e de uma nova migração.
